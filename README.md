# BGCDashboard & KYC Pipeline

## BGCDashboard

BGCDashboard is a simple AI-powered dashboard that brings business and operational data together in one place. It helps turn raw data into useful insights, metrics, and trends that are easier to understand and act on.

## KYC Pipeline

KYC Pipeline helps automate the KYC process by extracting information from documents, validating the data, and organizing the results. It reduces manual work and makes document verification faster and more consistent.
